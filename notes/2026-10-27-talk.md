# Software Discovery

> Lightning Talk, Leipzig Gophers #61, Halle/Saale, [Martin Czygan](mailto:martin.czygan@gmail.com)


## Motivation

I am trying to work through [my own ai-assisted coding challenge
list](https://github.com/miku/nightjet) and would like to know, what projects
are already out there. Inspiration, learning from other projects.

Also: Lots of projects that could have made sense in the past, may not be
relevant or useful today. Strange times.

## Software Reuse

* something long awaited
* but maybe, short lived

> Software reuse is finally here but comes with risks. -- "[Surviving Software Dependencies](https://dl.acm.org/doi/10.1145/3347446)", Russ Cox, 2019

## Build or Buy

* lots of small to medium sized project you can probably build and get
  tailormade solution (if you are lucky); examples:
  [gh-repos](https://github.com/miku/gh-repos),
  [doclingclient](https://github.com/miku/doclingclient),
  [tldhunter](https://github.com/miku/tldhunter), ...
* productivity gains are less visible, as we are just rebuilding things that already existed

Some observations:

* lots of interface-y code get obsolete very fast
* a data access layer seems to be useful: databases, code to feed that
* using an LLM is still expensive and anything that uses "software 1.0" is probably lightning fast and cheap
