# SIL1: design

> Software reuse is finally here but comes with risks. [R. Cox, 08 July 2019, ACM Queue](https://queue.acm.org/doi/10.1145/3329781.3344149)

A small, fast tool for software discovery. We index millions of project and
epositories and build a map that you can navigate with plain text.

## Inspiration

Patent

> patent — a prior-art search for your code ideas. [docs](https://docs.rs/patent/latest/patent/), [github](https://github.com/r14dd/patent)

> Takes a plain-English dev-tool idea and searches the open-source ecosystem —
> crates.io, npm, PyPI, GitHub, Go, Maven, NuGet, RubyGems, Docker Hub,
> Homebrew, Packagist, Hex, Artifact Hub, AUR, Hackage, Nixpkgs, the VS Code
> Marketplace, the JetBrains Marketplace, and Hacker News — for prior art, then
> gives an honest, scoped verdict on whether it’s already been built. The exact
> set searched is chosen per query; whichever sources actually responded are
> always surfaced.

> Integrity principle: this tool can prove something exists, but never that it
> doesn’t — it only searched some sources. All output is scoped to “what was
> found in the sources checked.”


## Outline

Find and harvest software package metadata. Find source repositories, but limit
scope (GH has in the order 100M public repos); we may want software that you
could reuse, and that software is often packaged in some form or another.
